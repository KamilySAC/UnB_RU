# Sistema de Gestão do Restaurante Universitário da UnB

Aplicação web para apoiar a gestão dos restaurantes universitários.

## Funcionalidades

- Gestão de restaurantes.
- Gestão de catracas vinculadas a restaurantes.
- Seleção de restaurantes e catracas na Aplicação de Controle.

> Atualize esta lista conforme as funcionalidades forem implementadas.

## Tecnologias

- Ruby: 3.4.11
- Rails: 8.1.4
