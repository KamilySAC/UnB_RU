Overview

Represents a student (estudante) using the university restaurant system.

A student belongs to a tariff group (Grupo I–IV) that determines the price paid per meal shift, and holds a balance (saldo) topped up via recharges.

Examples:

Fetching a student's lunch price

estudante.tarifa_para("Almoço") #=> 0.0e0 for Grupo I

def adicionar_recarga(recarga)
  transaction do
    recarga.estudante = self
    recarga.save!
    update!(saldo: (saldo + recarga.valor).round(2))
  end
  recarga
end
